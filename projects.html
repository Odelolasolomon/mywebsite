Named-Entity-Recognition-Using-Transformer-Architecture

This project develops a Transformer-based model for Named Entity Recognition (NER), an essential task in Natural Language Processing (NLP). The model is designed to accurately identify and classify named entities like names, locations, and organizations in text. Leveraging the self-attention mechanism of Transformers, the project demonstrates significant improvements in recognizing entities in real-world datasets, specifically the Broad Twitter Corpus (BTC). This project showcases expertise in sequence labeling, model fine-tuning, and real-world NLP applications, which are critical for tasks like information retrieval, content recommendation, and customer support.

Sarcasm-Classification-Using-BERT

This project fine-tunes Google's BERT model to detect sarcasm in tweets. Leveraging BERT’s advanced capabilities, it accurately classifies tweets as sarcastic or non-sarcastic. The implementation involves data handling with pandas and NumPy, model training using Keras and TensorFlow, and evaluation with scikit-learn. Visualizations are created with seaborn and Matplotlib to provide insights into the data and model performance. The final model shows strong performance in sarcasm detection, with detailed classification metrics provided.
